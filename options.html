Jonas Review Guesser: settings

This is the extension's own settings page. It isn't a website: its address starts with chrome-extension:// and nothing typed here is sent anywhere except, when you use it, your key to Anthropic's API. You can also set this up without leaving Steam: guess on any game and click Explain with Claude: set up your API key under the answer.

Explain with Claude (optional)

After you guess, the extension shows a few likely reasons for the review count from Steam's own data. With your own Anthropic API key it can also ask Claude for a short explanation.

About your key

  • It is stored only in this browser profile (chrome.storage.local). It is never written to the extension's files, so forks and copies of this repo don't contain it.
  • Requests go straight from the extension's background worker to api.anthropic.com; Steam's pages never see the key.
  • Each explanation is billed to your Anthropic account. Use a dedicated key and set a monthly spend limit in the Claude Console (platform.claude.com).
  • "Test key" checks the key, workspace and model by counting tokens, which is free; it doesn't run Claude.
