Jonas Review Guesser: settings

This is the extension's own settings page. It isn't a website: its address starts with chrome-extension:// and nothing typed here is sent anywhere except, when you use it, your key to Google's Gemini API. You can also set this up without leaving Steam: guess on any game and click Explain with Gemini: set up a free key under the answer.

AI explanations (optional, free)

After you guess, the extension shows a few likely reasons for the review count from Steam's own data. With a free Gemini API key it can also ask Gemini for a short explanation.

Create a free key in Google AI Studio (aistudio.google.com/apikey).

About your key

  • It's stored only in this browser profile (chrome.storage.local), never in the extension's files, so forks and copies of this repo don't contain it.
  • Requests go straight from the extension's background worker to generativelanguage.googleapis.com; Steam's pages never see the key.
  • Free tier: no charge, but daily limits apply and Google may use free-tier prompts to improve its products. The prompts are only public Steam data about the game.
  • "Test key" checks the key and model without generating anything.
