Jonas Review Guesser: settings

This is the extension's own settings page. It isn't a website: its address starts with chrome-extension:// and nothing typed here is sent anywhere except, when you use it, your key to the AI provider you pick. You can also set this up without leaving Steam: guess on any game and click Explain with AI: set up a key under the answer.

AI explanations (optional)

After you guess, the extension shows a few likely reasons for the review count from Steam's own data. With an AI key it can also ask an AI model for a short explanation.

Create a free key in Google AI Studio (aistudio.google.com/apikey).

Create a key in the Claude Console (platform.claude.com).

About your keys

  • They're stored only in this browser profile (chrome.storage.local), never in the extension's files, so forks and copies of this repo don't contain them.
  • Requests go straight from the extension's background worker to generativelanguage.googleapis.com (Gemini) or api.anthropic.com (Claude); Steam's pages never see a key.
  • Gemini free tier: no charge, but daily limits apply and Google may use free-tier prompts to improve its products. The prompts are only public Steam data about the game.
  • Claude: each explanation is billed to your Anthropic account (or your Max/Team plan's monthly API credits). Use a dedicated key with a spend limit.
  • "Test key" checks the key and model without generating anything, which is free.
